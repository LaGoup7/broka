Générateur de QR Code

Créer votre QR Code permanent

Ce QR code sera imprimé et utilisé sur les marchés. L'URL ne doit jamais changer — le contenu de la page peut évoluer, pas le lien.

Mettre en ligne sur yourqr.page

  • 1
    Connectez-vous à Infomaniak Manager → Hébergement Web → votre espace → Gestionnaire de fichiers
  • 2
    Dans le dossier web/ (ou public_html/), créez un dossier broka et uploadez-y tout le contenu du dossier local broka/ (index.html, stand.html, images/…)
  • 3
    La page sera accessible à yourqr.page/broka/ — collez cette URL dans le champ ci-dessus et générez votre QR code
  • 4
    Téléchargez le PNG, imprimez-le → c'est votre QR code permanent. Vous pouvez modifier le contenu de la page à tout moment sans rechanger le QR.
